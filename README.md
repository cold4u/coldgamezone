# ⚡ ColdGameZone

**The Premier Cyber Arcade & Web Gaming Portal**

ColdGameZone is a studio-grade web gaming portal containing 29 games built entirely with pure HTML5 Canvas 2D vector graphics, real-time Web Audio API sound synthesizers, and zero external runtime dependencies.

---

## 🎮 The 29-Game Roster

### 🥊 Action & Combat
- **Cyber Brawler: Neon Clash** (`fighter/`): Best 2 of 3 2D fighting game with punches, kicks, fireballs, and guard block chip KO.
- **Neon Shinobi** (`shinobi/`): Fast-paced action slasher with double jumps, wall kicks, and bullet parrying.
- **Cyber Strike** (`strike/`): Space bullet hell vertical shooter with 5-tier weapon upgrades and full-screen EMP waves.
- **Cyber Survivor** (`survivor/`): Bullet heaven roguelite with auto-firing plasma cannons and perk synergy trees.
- **Aero Striker** (`flight/`): 2.5D rail flight combat with lock-on torpedoes, barrel rolls, and colossal mothership boss.
- **Ghost Protocol** (`stealth/`): Top-down espionage infiltration with 2D vision cones, silent takedowns, and laser grids.
- **Neon Defense** (`defense/`): 360-degree orbital defense turret against incoming missile swarms.

### 🏎️ Racing & Speed
- **Turbo Drive** (`game/`): Highway traffic racer with nitro boost, multiple vehicles, and rocket launchers.
- **Cyber Drift** (`kart/`): Mode-7 style pseudo-3D racer with 3-tier drift boost sparks and battlefield weapons.
- **Gravity Runner** (`runner/`): Endless runner with instantaneous gravity inversion between floor and ceiling.

### 🤖 Strategy & Tactics
- **Mech Warfare** (`tactics/`): 8x8 isometric grid turn-based tactics commanding 3 mechs against cyborg swarms.
- **Matrix Defense** (`tower/`): Grid tower defense with 4 specialized towers and 3-tier upgrade trees.
- **Cyber City Tycoon** (`tycoon/`): City power grid simulation with day/night solar cycles and battery storage.
- **Cyber Deck** (`deck/`): Roguelike card battler with 3-energy economy and telegraphed enemy intents.

### 🧩 Puzzle & Brain
- **Cyber Circuit** (`puzzle/`): 30 handcrafted logic wire connection stages + infinite generator.
- **Quantum Portal** (`portal/`): Dual-portal physics puzzle with momentum preservation and test chambers.
- **Quantum Fall** (`tetris/`): Standard SRS falling block puzzle with 7-bag randomizer, hold slot, and 4-line TETRIS! clears.
- **Neon Alchemist** (`match/`): Match-3 RPG spellcaster with active boss turn timers.

### 👾 Arcade Classics
- **Quantum Maze** (`pacman/`): Classic maze chase with direction buffering and 4 distinct ghost AIs.
- **Cyber Bomber** (`bomber/`): 15x13 tactical arena bomber with 4-way cross blast propagation and 3 bot AIs.
- **Neon Snake** (`snake/`): Vector snake with speed multipliers and ghost wall-phasing mode.
- **Neon Breaker** (`breaker/`): Dynamic angle brick breaker with multi-ball cascades and laser paddles.
- **Quantum Pinball** (`pinball/`): Physics arcade pinball with pop bumpers, drop targets, and 3-ball Multiball.
- **Neon Pool** (`billiards/`): 2D 9-ball billiards with 4x sub-stepped elastic collisions and cushion bounce spin.

### ⛏️ Adventure & Exploration
- **Deep Core** (`mining/`): Subterranean pod exploration mining 5 ore tiers with workshop upgrades.
- **Quantum Mini-Golf** (`golf/`): 9 championship holes with quantum wormholes, gravity vortices, and booster pads.
- **Neon Rogue** (`rogue/`): Top-down dungeon crawler with katana/shotgun loadouts and i-frame dash rolls.
- **Quantum Jump** (`jump/`): Vertical infinite platformer with spring coils and crumbling platforms.
- **Cyber Pulse** (`pulse/`): 4-lane rhythm action game with synchronized procedural synthwave tracks.

## 🚀 Running Locally

Serve the directory with any local static HTTP server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
